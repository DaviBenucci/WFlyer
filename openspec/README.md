# OpenSpec do site institucional

Toda mudança relevante deve conter:

```text
openspec/changes/<id>/
├── proposal.md
├── design.md
├── tasks.md
└── acceptance.md
```

## Campos mínimos

- problema;
- escopo;
- fora de escopo;
- documentos normativos afetados;
- riscos;
- impacto em acessibilidade;
- impacto em performance;
- impacto em segurança;
- tarefas ordenadas;
- critérios de aceite;
- rollback.

A proposta não autoriza mudança de stack sem ADR explícito.
