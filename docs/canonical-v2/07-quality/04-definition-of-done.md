The v2 website is complete only when:

- canonical docs/OpenSpec/manifests match implemented behavior;
- all linear phases/gates are complete;
- Music Gates A/B/C have human approval;
- final Persona and demo media assets are approved/integrated;
- desktop native-scroll story, header traversal, history, hashes, and score continuity pass;
- mobile vertical order and reduced-motion mode pass;
- detailed routes, legal pages, Contact, SEO, and deployment remain functional;
- no legacy company positioning, header app-access link, previous/next chapter controls, route-transition overlay, hard-coded music geometry, or interactive fake demo remains in the v2 landing;
- accessibility, performance, failure recovery, cleanup, visual, unit, component, E2E, motion, build, standalone, and staging gates pass;
- exact-SHA staging and rollback evidence exists;
- Davi Benucci records explicit homologation;
- production is deployed only after separate explicit authorization.
