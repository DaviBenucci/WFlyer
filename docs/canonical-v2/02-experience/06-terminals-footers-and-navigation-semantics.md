# Terminals, Footers, and Navigation Semantics

## Portfolio terminal

```text
Contato → musical cadence → final barline → Professional terminal
```

The terminal uses shared footer data and does not maintain independent legal or
contact content.

## Mobile / vertical mode

Home and the Professional chapters are followed by one semantic global footer.
The Professional visual ending is not a duplicate footer. Standalone routes
retain the shared site footer.

## Footer content

- W_Flyer personal professional description;
- Sobre, Serviços, Processo, Projetos, Contato;
- legal and accessibility links;
- approved email, GitHub, Instagram, and copyright.

## Navigation semantics

- Score graphics are decorative by default (`aria-hidden`).
- Real navigation uses links and buttons to surviving destinations.
- Detailed routes remain usable without the immersive story.
- A final barline is narrative geometry, not a link or landmark.
