# User Journeys, Conversion, and Content Boundaries

## Professional visitor

```text
Home → About → Services → Process → Projects → Contact → professional ending
```

The visitor may use the header to accelerate but still traverses the story.

## Application visitor

Desktop can move from Home toward the application branch. Mobile reaches the application after the professional branch:

```text
Application → How It Works → Benefits → Demonstration → Access W_Flyer → application ending
```

## Header visitor

Header click resolves a canonical target progress and animates native scroll through intermediate chapters. It never teleports or mounts route pages as transitions.

## Public application boundaries

Allowed:

- problem, audience, proposition;
- public five-step workflow;
- approved benefits;
- authorized screenshots/video;
- product-development status;
- link to application.

Not allowed:

- internal OCR/OMR/prompt/provider/pipeline details;
- database or security internals;
- accuracy guarantees;
- unapproved roadmap;
- fake live processing.

## Project publication

Only explicitly authorized cases. Initial set:

- W_Flyer;
- MSN Distribuidora;
- MSN Suprimentos.
