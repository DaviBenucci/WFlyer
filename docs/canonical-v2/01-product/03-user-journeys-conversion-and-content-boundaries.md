# User Journeys, Conversion, and Content Boundaries

## Portfolio visitor

```text
Home → Sobre → Serviços → Processo → Projetos → Contato → footer
```

Desktop may progressively enhance this into horizontal presentation. Mobile,
reduced motion, JavaScript failure, and motion failure retain the same semantic
order vertically.

## Header visitor

A header action resolves a canonical surviving target and traverses the same
native-scroll story through intermediate chapters. It does not mount route pages
as transitions or maintain a parallel progress state.

## Conversion

Contact is the sole professional conversion terminal. It preserves validation,
anti-abuse, consent, failure, duplicate-submission, recovery, focus, and secure
server-only provider contracts.

## Content boundaries

Only approved services and projects may be published. Initial projects are
W_Flyer, MSN Distribuidora, and MSN Suprimentos. Do not invent results, metrics,
clients, testimonials, or private implementation details.

The independent musical application has no institutional journey in this site.
