# Scope, Status, and Terminology

## Website scope

`wflyer.com.br` is:

- a personal professional portfolio;
- a service-acquisition surface;
- a public presentation of the W_Flyer musical application;
- a narrative visual experience under the W_Flyer brand.

It is not presented as “W_Flyer company.”

## Separate application

`app.wflyer.com.br` remains separate. This repository must not implement or modify application authentication, OCR/OMR, score processing, transposition, storage, database, or administration.
