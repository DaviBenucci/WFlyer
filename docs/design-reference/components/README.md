# Referências de componentes

## Header e navegação

- header default claro/escuro;
- compasso hover/focus;
- aplicação ativa;
- empresa ativa;
- capítulo terminal ativo;
- menu mobile aberto;
- navegação anterior/próximo;
- símbolo central durante handoff.

## Partitura

- âncora de entrada;
- âncora de saída;
- conector temporário;
- nota ativa;
- barra de compasso;
- barra dupla final claro/escuro.

## Tablet

- idle claro/escuro;
- controle focado;
- configured;
- processing;
- result;
- reset;
- reduced motion;
- mobile.

## Formulário

- default;
- erro por campo;
- erro geral;
- enviando;
- sucesso;
- falha de Turnstile;
- consentimento focado.

## Conteúdo

- cards de serviço;
- estado vazio do portfólio;
- botões primário/secundário;
- toggle de tema;
- footer intermediário e terminal.

As referências devem ser produzidas pelo projeto, aprovadas pelo usuário e nunca derivadas por recorte das imagens de inspiração.
