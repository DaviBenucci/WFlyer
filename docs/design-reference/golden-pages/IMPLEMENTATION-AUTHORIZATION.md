# Autorização de implementação visual

**Estado:** `AUTHORIZED_FOR_FULL_IMPLEMENTATION`

O proprietário autorizou o Codex a implementar todas as páginas usando os exemplos já existentes. A geração de novas imagens individuais passa a ser opcional para refinamento e não é gate pré-código.

## Conjunto mínimo obrigatório

1. prancha mestra aprovada;
2. Aplicação — desktop claro;
3. tokens visuais;
4. especificação de páginas;
5. arquétipos visuais;
6. regras de responsividade;
7. catálogo e storyboards textuais de motion.

## Como derivar

- tema escuro: mesma geometria, tokens escuros e densidade observada na prancha;
- mobile: reorganização vertical conforme regras, preservando hierarquia e continuidade musical;
- páginas editoriais: usar arquétipo editorial;
- cards: usar padrões de Serviços e Portfólio;
- Processo: combinar pauta contínua e sequência numerada;
- detalhes de serviço: combinar hero editorial, conteúdo modular e CTA;
- legais: layout editorial simplificado.

## Proibição

A autorização não permite alterar logo, paleta, tipografia, estrutura do header, direção das partituras, stack ou conteúdo oficial.
