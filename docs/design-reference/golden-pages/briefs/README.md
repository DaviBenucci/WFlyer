# Briefs opcionais de geração

Estes arquivos podem ser usados para produzir imagens adicionais durante QA ou refinamento. Eles não são requisitos pré-código e não alteram a autorização `READY_FOR_IMPLEMENTATION`.

A fonte principal para o Codex é:

1. prancha mestra;
2. Aplicação desktop claro;
3. `visual-archetypes.yaml`;
4. `page-matrix.yaml`;
5. especificações de página, tokens e responsividade.

Toda nova imagem nasce como `pending-approval` e somente substitui um estado derivado se o usuário aprová-la explicitamente.
