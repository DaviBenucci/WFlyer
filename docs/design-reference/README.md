# Referências visuais

## Estrutura

- `inspiration/`: imagens fornecidas pelo usuário, somente para inspiração;
- `golden-pages/`: referências originais aprovadas da página completa;
- `components/`: estados visuais originais de componentes;
- `storyboards/`: quadros de animação;
- `schemas/`: manifestos e metadados.

A IA deve consultar simultaneamente:

1. especificação textual;
2. referência visual original aprovada;
3. tokens;
4. critérios de aceite.

Uma imagem de inspiração nunca substitui uma especificação e nunca pode ser enviada ao produto.
